Backup

Export saves every page as a single JSON file you can keep or move to another browser. Importing adds pages alongside what's already here — it won't overwrite anything.

When this is on, Export asks for a password and locks the file with it; Import will ask for that same password to read an encrypted file back.

Privacy

Asks for a short PIN before showing the notebook on this device. This is a privacy screen for casual snooping, not real security — the notes are still stored as plain text in this browser, so it won't stop anyone with access to the browser's developer tools.
